# SCPC 2026 예선 2차 — Mission 선언

**참가자(데이콘 닉네임): SDH**

**Mission 이름: 채비(Chebi) — 유효조건 원장 기반 진화형 외출 준비 코파일럿**

## 대상 사용자

반복 외출 루틴 2개(평일 출근, 주 2회 수영 강습)를 가진 1인 직장인 **합성 페르소나 "대혁"**.
매일 아침 가방·복장·출발시간을 준비하고, 소모성 준비물(우산·세면용품 등)의 잔량을 함께
관리한다. 모든 일정·날씨·권한·배송 사건은 앱 내부의 합성 이벤트와 가상시간으로 재현하며,
실제 서비스 계정·결제·연락처·위치는 사용하지 않고 모든 산출물은 draft/preview로만 존재한다.

## 핵심 문제

준비 체크리스트 도구는 두 방향으로 실패한다. (a) 매번 처음부터 다시 물어 입력 부담이 줄지
않거나, (b) 지난 플랜을 통째로 재사용해 일회성 항목이 유령처럼 재등장하고, 만료된 추론이
계속 적용되며, 조건이 바뀐 날에도 과거 방식을 밀어붙인다. 문제의 본질은 "기억을 얼마나
쓰느냐"가 아니라 **"어떤 기억이 지금도 유효한지 판별하고, 무효가 된 부분만 고치는 것"**이다.

## 장기 목표

episode가 반복될수록 ① 사용자 입력·확인 단계가 감소하고, ② 잘못된 재사용(일회성 재등장,
만료된 추론 적용, 삭제 원문 부활)이 0건으로 유지되며, ③ 목표·상황·권한 변화 시
질문·대기·보류·재계획·중단을 근거와 함께 선택하고, ④ 오보·정정 시 영향받은 성분만 되돌리며,
⑤ 소모품 부족 시 보충 draft를 만들고 며칠 뒤(가상시간) 도착 결과가 이후 준비 판단에 실제
반영되는 — 세션과 프로세스 재실행을 넘어 이어지는 **진화하는 준비 플랜**을 유지한다.

## Primary value

**"덜 묻되, 틀리게 재사용하지 않는다."** 자동화의 이득(입력 감소)과 안전(무효 기억 차단,
안전 정지, 최소 복구)을 하나의 게이트로 동시에 달성하고, 그 전부를 수치로 증명한다.

## E1–E4 인과관계

하나의 영속 상태(준비 플랜 버전체인 + 기억 원장)가 네 단계를 관통한다.
**[E1 Learn]** 첫 준비에서 항목·이동시간·제출물을 학습하며 각 기억을 사실(FACT) /
추론(INFERENCE) / 일회성(EPHEMERAL)으로 구분하고 유효조건(요일·강수·만료·권한)과 출처를
기록한다 — 이 분류가 이후 모든 동작의 원인이 된다.
**[E2 Reuse]** 다음 유사 준비에서 유효조건을 통과한 기억만 자동 재사용해 입력을 줄이고
(일회성 항목은 재등장하지 않음), 실제 사용 기록으로 이동시간·소모품 추론을 갱신하며, 재고
부족 시 보충 draft를 생성한다.
**[E3 Exception]** 날씨 정정·일정 변경·권한 회수 같은 합성 사건이 저장된 방식과 충돌하면
과거 방식을 고집하지 않고, 유효조건 매칭으로 영향 항목을 특정해 질문·대기·보류·재계획·중단
중 적절한 판단을 내린다.
**[E4 Recover]** 오보 정정·부분 철회 시 출처 링크를 역추적해 영향받은 성분만 롤백하고
유효한 학습은 보존하며, 복구된 플랜으로 다음 준비가 정상 진행되어 입력 감소가 이어진다.
앞 episode의 선택(기억 분류, 권한 허용/거부, 삭제, 보충 주문)이 뒤 episode의 프리필 내용,
가능한 행동(버튼 활성/비활성), 도착 결과 반영을 서로 다른 지점에서 실제로 변경한다.

## Mobile constraint

주 제약 = **선택 권한(위치)의 거부·중도 회수**: 전 경로는 권한 없이 동작(이동시간을 수동값으로
대체)하되, 권한 상태 자체가 기억의 유효조건으로 취급되어 판단 분기를 실제로 바꾼다.
부 제약 = **process 강제 종료·재실행** 후 플랜·보류 질문·가상시각을 원장에서 복구(local
continuity)하며, 오프라인에서도 판단·복구·export가 동작한다.

## Signature mechanism — VG-Ledger (Validity-Gate Ledger)

모든 기억 항목에 {유형(사실/추론/일회성), 유효조건 술어, 출처 링크, tombstone}을 부여하고,
결정론적 게이트가 세 지점에서 작동한다: ① **재사용 게이트** — 유효조건 통과분만 프리필,
② **충돌 게이트** — 신규 이벤트를 유효조건과 매칭해 영향 항목만 특정하고 판단 카드 생성,
③ **복구 게이트** — 출처 역추적으로 영향 성분만 롤백.

**문제 claim**: 유형·유효조건 없는 기억 재사용은 유령 항목, 만료된 추론의 적용, 과잉 재확인,
과잉 복구를 낳는다.
**효과 claim**: 게이트가 켜지면 입력 부담이 줄면서도 잘못된 재사용이 0이 되고, 정지·복구가
최소 범위로 정밀해진다. 같은 APK의 claim-off(게이트만 우회, 저장·화면·이벤트 동일) 대비
사용자 입력 단계 수, 잘못된 재사용 건수, 영향 특정 정확도, 복구 보존율로 측정한다.
