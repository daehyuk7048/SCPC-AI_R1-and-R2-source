# 선언문에서 파생된 구현 계약 (검토 렌즈 3 판정 — 문서 아닌 구현·기술노트 의무)

동결된 선언 문구를 지키기 위해 구현이 반드시 충족해야 할 최소 계약:

1. **E2 "이동시간·잔량 추론 갱신"** — 최소 구현: 합성 사용 이벤트 1건(예: 실제 출발 5분 지연)
   → 이동시간 INFERENCE 값 1회 결정론적 갱신이면 문면 충족 (UPSERT/CORRECT 1스텝, ML 불요).
   잔량 갱신은 보급 흐름에서 자연 충족. 시나리오에 사용 기록 이벤트 배치 필요.

2. **claim-off arm 정상 완주** — 기술노트(MISSION_AND_TECHNICAL_NOTE)에 "claim-off arm도 전
   episode를 정상 완주하는 보수적 기본 동작"임을 한 문장 명시하고, comparison 실행에서 off arm
   정상 완료 evidence를 남길 것 ("일부러 약한 데모" 공격 방어).

3. **"영향 특정 정확도" 지표의 ground truth** — 비교 시나리오 스펙에 각 충돌 이벤트의 실제 영향
   항목 집합을 명기해야 지표가 정의됨 (full: 특정 집합 vs GT, off: 전체 재확인).

4. **E4 "버튼 활성/비활성 등"** — 가능행동 변화 중 최소 1개는 실제 버튼 활성/비활성 토글로 구현
   (선언 괄호 예시를 실물로 보유).

5. **권한 상태 이원 설계** — 앱 UI 경로: Android OS 실제 runtime permission (G7 근거).
   Probe 경로: REVOKE_SCOPE 등 합성 이벤트도 같은 "권한 상태" 입력으로 처리 (harness는 OS 권한을
   통제하지 않음). 선언문은 "권한 상태가 판단 분기의 실제 입력"으로 중립 표현 — 두 경로 모두 충족.

6. **분량** — PDF 조판 시 1쪽 실측. 넘치면 비동결 절(모바일 이유·Signature mechanism)부터 압축,
   동결 5필드 문구는 불변.
